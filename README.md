# Flash Report

Arma el flash report fotográfico de faena a partir de la plantilla Excel.

## Abrir

Doble clic en `Abrir_Flash_Report.bat`.

Si hay Python, abre http://127.0.0.1:8765/index.html. Si no hay Python, abre `index.html` directo.

También está en [GitHub Pages](https://zettafuego.github.io/Flash-ReportdeFotoCasma/).

## Qué hace

Cargas las fotos del turno. La página llena `plantilla_flash_report.xlsx` y descargas el archivo. ExcelJS va incluido en el repositorio.

No subas reportes ya llenos ni fotos de faena. La plantilla vacía sí puede quedarse.

## Stack

HTML, CSS y JavaScript.
